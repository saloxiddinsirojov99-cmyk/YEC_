# YEC Market Frontend

## Texnologiyalar
- Next.js (App Router)
- TypeScript
- TailwindCSS
- Axios

## Muhim route'lar
- `/`
- `/carpets`
- `/carpets/[id]`
- `/login`
- `/register`
- `/profile`
- `/orders`
- `/contact`
- `/about`

## Ishga tushirish
1. `.env.example` nusxa olib `.env.local` yarating.
2. `NEXT_PUBLIC_API_BASE_URL=http://localhost:3001/api/v1` ni tekshiring.
3. `npm install`
4. `npm run dev`
