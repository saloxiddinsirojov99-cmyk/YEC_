# YEC Market Monorepo

- `backend/` - NestJS + Prisma + PostgreSQL backend
- `front/` - Frontend uchun papka (UI kodlari shu yerga qo'yiladi)

## Ishga tushirish

1. Rootdan: `npm run start:dev` (backend dev server)
2. Yoki alohida:
3. `npm run backend:dev`
4. `npm run front:dev`
5. Swagger: `http://localhost:3001/docs`
